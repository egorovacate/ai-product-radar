# AI Product Radar

Персональный архив подробных двуязычных новостных дайджестов об AI, разработке и продуктах. Каждый выпуск публикуется на русском и британском английском без сокращения аналитической глубины.

Онлайн-архив: https://egorovacate.github.io/ai-product-radar/

Запуск в Codex:

> Используй $ai-product-radar и собери дайджест за последние 3 дня.

Каждый выпуск сохраняется как связанная пара JSON и HTML — RU и EN. `public/index.html` содержит общий архив и ссылки на обе версии. После проверки агент отправляет новый выпуск в `main`, и постоянная ссылка на GitHub Pages обновляется автоматически.

Локальный просмотр:

```bash
npm run preview
```

Затем открыть `http://localhost:4173`.
