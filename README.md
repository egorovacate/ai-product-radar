# AI Product Radar

Персональный архив подробных новостных дайджестов об AI, разработке и продуктах.

Онлайн-архив: https://egorovacate.github.io/ai-product-radar/

Запуск в Codex:

> Используй $ai-product-radar и собери дайджест за последние 3 дня.

Каждый выпуск сохраняется в `data/digests` как JSON и публикуется отдельной страницей в `public/digests`. `public/index.html` содержит общий архив. После проверки агент отправляет новый выпуск в `main`, и постоянная ссылка на GitHub Pages обновляется автоматически.

Локальный просмотр:

```bash
npm run preview
```

Затем открыть `http://localhost:4173`.
